# 鸡蛋采购登记

记录采购日期、鸡蛋数量、总价、商家和备注，让网站自动计算每枚单价并扣减可用经费。

## 操作边界

- 使用 `https://egg-budget-cn.lifangyuanaa643449.chatgpt.site/#overview`。
- 仅通过网站表单完成正常登记；不要直接改写 `localStorage`，也不要为登记数据修改网站源码。
- 业务数据保存在操作所用浏览器的 `localStorage` 键 `egg-budget-tracker:v1` 中。把成功范围表述为“已在当前浏览器/设备登记”，不要称为全局、云端或所有同事均已同步。
- 如果没有可操作网页的浏览器或 computer-use 工具，停止在提交之前；给出规范化字段和手动操作步骤，不要声称登记成功。
- 除非用户明确要求，不要删除、修改或恢复示例数据。

## 规范化输入

1. 提取采购日期、鸡蛋数量、总价、商家和备注。
2. 要求鸡蛋数量为大于 `0` 的整数，单位为“枚”。
3. 要求总价为大于 `0` 的人民币数值，最多保留两位小数。不要让用户填写单价；网站按 `总价 ÷ 数量` 自动计算。
4. 日期缺失时使用用户本地时区的今天，并转换为 `YYYY-MM-DD`。
5. 商家缺失且上下文没有暗示其他商家时，使用表单默认值“盒马”并在结果中明确说明；商家存在歧义时先追问。
6. 备注缺失时保留为空，不要编造用途或品种。
7. 用户一次提供多笔采购时，先拆成独立条目，再逐笔提交和核验。

## 登记流程

1. 打开或复用目标网站，确认页面标题为“鸡蛋经费统计”。
2. 在“总览”读取当前“可用金额”，然后点击“新增采购”。
3. 在“新增采购”对话框中按标签填写：
   - “采购日期”
   - “鸡蛋数量”
   - “总价”
   - “商家”
   - “备注”
4. 核对“单价（自动计算）”为 `总价 ÷ 数量` 的合理结果。内部单价保存四位小数，页面通常显示两位小数。
5. 如果总价会使可用金额变为负数，在提交前向用户明确提示并取得确认；不要假设网站会阻止超支。
6. 点击“保存记录”一次。不要在页面仍在处理或结果不明时重复点击。
7. 确认出现“采购记录已新增”状态提示。

## 核验与回复

1. 打开“采购记录”，清除会隐藏目标记录的月份筛选。
2. 确认列表中存在匹配的日期、数量、总价、商家和备注，并读取自动计算的每枚单价。
3. 返回“总览”时，能读取则确认“已花费金额”增加了本次总价且“可用金额”相应减少。
4. 只有状态提示与列表记录均匹配时才报告成功。
5. 用简短结果回复：登记设备范围、日期、数量、总价、每枚单价、商家、备注和核验后的可用金额。失败时说明具体阻断点和未提交状态。
