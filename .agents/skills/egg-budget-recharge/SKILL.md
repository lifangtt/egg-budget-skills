# 鸡蛋经费充值

在现有网站中登记一笔或多笔充值，并在提交后核验记录与余额变化。

## 操作边界

- 使用 `https://egg-budget-cn.lifangyuanaa643449.chatgpt.site/#overview`。
- 仅通过网站表单完成正常登记；不要直接改写 `localStorage`，也不要为登记数据修改网站源码。
- 业务数据保存在操作所用浏览器的 `localStorage` 键 `egg-budget-tracker:v1` 中。把成功范围表述为“已在当前浏览器/设备登记”，不要称为全局、云端或所有同事均已同步。
- 如果没有可操作网页的浏览器或 computer-use 工具，停止在提交之前；给出规范化字段和手动操作步骤，不要声称登记成功。
- 除非用户明确要求，不要删除、修改或恢复示例数据。

## 规范化输入

1. 提取充值金额、充值日期和备注。
2. 要求金额为大于 `0` 的人民币数值，最多保留两位小数。金额缺失或含义不明确时，只追问这一项。
3. 日期缺失时使用用户本地时区的今天，并转换为 `YYYY-MM-DD`；不要用 UTC 日期替代本地日期。
4. 备注缺失时保留为空，不要虚构资金来源。
5. 用户一次提供多笔充值时，先列出规范化后的批次，再逐笔提交和核验。

## 登记流程

1. 打开或复用目标网站，确认页面标题为“鸡蛋经费统计”。
2. 在“总览”点击“新增充值”。
3. 在“新增充值”对话框中按标签填写：
   - “充值日期”
   - “充值金额”
   - “备注”
4. 点击“确认充值”一次。不要在页面仍在处理或结果不明时重复点击。
5. 确认出现 `已充值 ¥...` 状态提示；若出现表单错误，按原值修正后只重试一次。

## 核验与回复

1. 打开“充值记录”，确认列表中存在匹配的日期、金额和备注。
2. 核对“累计充值”或“总充值金额”已按本次金额增加；能读取时同时记录当前结余。
3. 只有状态提示与列表记录均匹配时才报告成功。
4. 用简短结果回复：登记设备范围、日期、金额、备注和核验后的累计充值/结余。失败时说明具体阻断点和未提交状态。
