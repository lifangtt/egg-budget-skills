# 鸡蛋食用登记

记录某人在指定日期吃了多少枚鸡蛋，让网站按当前平均每枚成本自动计算并锁定本次花费。

## 操作边界

- 使用 `https://egg-budget-cn.lifangyuanaa643449.chatgpt.site/#overview`。
- 仅通过网站表单完成正常登记；不要直接改写 `localStorage`，也不要为登记数据修改网站源码。
- 业务数据保存在操作所用浏览器的 `localStorage` 键 `egg-budget-tracker:v1` 中。把成功范围表述为“已在当前浏览器/设备登记”，不要称为全局、云端或所有同事均已同步。
- 如果没有可操作网页的浏览器或 computer-use 工具，停止在提交之前；给出规范化字段和手动操作步骤，不要声称登记成功。
- 除非用户明确要求，不要删除、修改或恢复示例数据。

## 规范化输入

1. 提取姓名、鸡蛋数量和食用日期。
2. 要求姓名为非空文本；不要猜测未提供的人名。
3. 要求数量为大于 `0` 的整数，单位为“枚”；不要把金额或盒数当作鸡蛋数量。
4. 日期缺失时使用用户本地时区的今天，并转换为 `YYYY-MM-DD`。
5. 用户一次提供多人或多天记录时，拆成独立条目并保留原始对应关系。

## 成本规则

- 网站按全部采购记录的加权平均成本计算：`采购总价合计 ÷ 采购鸡蛋数量合计`。
- 登记时每枚成本保存为四位小数，本次花费保存为 `数量 × 每枚成本` 后的两位小数。
- 本次保存的成本不会因之后新增采购而变化。
- 没有任何有效采购记录时，网站不能保存食用登记。遇到“请先登记至少一笔采购记录”时停止，并建议先使用 `$egg-budget-purchase`；不要伪造单价或花费。

## 登记流程

1. 打开或复用目标网站，确认页面标题为“鸡蛋经费统计”。
2. 在“总览”点击“新增食用”。
3. 在“登记食用”对话框中按标签填写：
   - “食用日期”
   - “姓名”
   - “吃了多少鸡蛋”
4. 读取“本次自动分摊花费”预览；确认其为有效的非负金额。
5. 点击“保存食用登记”一次。不要在页面仍在处理或结果不明时重复点击。
6. 确认出现“食用登记已新增，花费已自动计算”状态提示。

## 核验与回复

1. 打开“食用记录”，清除会隐藏目标记录的筛选条件。
2. 确认列表中存在匹配的日期、姓名和数量，并读取登记时每枚成本与本次花费。
3. 只有状态提示与列表记录均匹配时才报告成功。
4. 用简短结果回复：登记设备范围、日期、姓名、数量、每枚成本和本次花费。批量登记时逐条列出成功或失败，不要用一条成功提示代替整批核验。
